الشفرة - موقع مفتوح لأي أحد بدون تسجيل دخول
==========================================

اللاعبون يفتحون الرابط فقط، لا يحتاجون أي حساب. الحساب مطلوب منك أنت مرة واحدة لنشر الموقع.
الخطوات تأخذ نحو ١٠ دقائق.

الخطوة ١: ارفع الملفات إلى GitHub
  - سجّل في github.com إن لم يكن عندك حساب (مجاني).
  - افتح github.com/new واكتب اسم المستودع: shifra واختر Public ثم Create repository.
  - اضغط على رابط «uploading an existing file».
  - افتح هذا المجلد بعد فك الضغط، حدّد كل الملفات (server.js و index.html و package.json
    و render.yaml و .gitignore) واسحبها إلى الصفحة. لا ترفع ملف الـ zip نفسه.
  - اضغط Commit changes.

الخطوة ٢: انشر على Render
  - افتح render.com وسجّل الدخول بحساب GitHub.
  - اضغط New ثم Web Service واختر مستودع shifra.
  - اضبط: Runtime = Node،  Build Command = npm install،  Start Command = node server.js
    واختر خطة Free (المجانية).
  - اضغط Deploy. بعد دقيقة أو دقيقتين يظهر رابط مثل  https://shifra-xxxx.onrender.com
  - هذا هو موقع اللعبة. أرسله لأصحابك، يفتحونه من أي جوال ويلعبون بدون أي تسجيل.

ملاحظات مهمة
  - الخطة المجانية في Render تنام بعد ١٥ دقيقة بدون زوار. أول فتح بعد النوم يتأخر من ٣٠ إلى ٦٠ ثانية.
    افتحوا الرابط قبل بدء اللعب بدقيقة. وتضيع الغرف المحفوظة عند النوم، فتنشئون غرفة جديدة.
  - لا يوجد في الموقع حساب أو كلمة سر. أي شخص عنده رمز الغرفة (٥ خانات) يدخلها،
    فلا تنشروا رمز غرفتكم علناً.
  - الخادم يحدّ عدد الغرف (٣٠٠) واللاعبين في الغرفة (٤٠) ويحذف الغرف بعد ٢٤ ساعة.
  - يمكن استخدام أي استضافة تشغّل Node.js بنفس الأمر: node server.js
    (المنفذ يؤخذ من المتغير PORT تلقائياً).
  - لتجربته على جهازك قبل النشر: node server.js ثم افتح http://localhost:8080
